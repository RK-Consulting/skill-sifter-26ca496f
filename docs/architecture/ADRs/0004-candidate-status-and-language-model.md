# ADR 0004: Candidate Status and Generic Language Expertise

**Status:** Proposed  
**Decider:** Product owner  
**Related issue:** V04-05

## Context

The current candidate model has a `jlptlanguage` field. V1 must support generic language expertise and distinguish the candidate relationship status from assignment-specific status.

## Decision required

Define candidate statuses, language/proficiency framework/level relationships, data migration, validation, and release scope.
