# Architecture Decision Records

Use an ADR for a significant and durable technical or domain decision: tenant identity, migration approach, recruitment-state transitions, audit-event design, external service boundaries, or a material API contract.

Create records as `NNNN-short-title.md` and link the deciding GitHub issue.

```md
# ADR NNNN: Title

**Status:** Proposed | Accepted | Superseded  
**Date:** YYYY-MM-DD  
**Decider:** Product owner  
**Related issue:** #123

## Context

## Options considered

## Decision

## Consequences
```
